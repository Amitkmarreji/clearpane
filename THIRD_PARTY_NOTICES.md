## Not copied, but credited

The conversion approach (merging host rules into `requestDomains`, validating
regex rules at install time, registering per-site scriptlets) follows ideas
from uBlock Origin Lite (GPLv3, https://github.com/uBlockOrigin/uBOL-home) and
Brave's adblock-rust (MPL-2.0, https://github.com/brave/adblock-rust). No code
was copied from either. The scriptlets in `src/scriptlets/lib.js` are original
implementations written from uBlock Origin's public scriptlet documentation,
so that the filter lists' `+js()` rules keep working.

The surrogate files in `redirects/` (noop scripts, a transparent pixel,
silent media, and analytics and ad stubs) were written for this project.
